# FUTURE_PE_01
# AI Website Copy Generator for Local Businesses
## 📌 Project Overview

This project focuses on building a structured AI prompt system to generate high-quality, conversion-focused website copy and design content for local businesses. The goal is to demonstrate how prompt engineering can be used to create professional website content efficiently while maintaining a consistent brand voice.

**Business Chosen:** Golden Hour Cafe

**Industry:** Cafe / Restaurant

---

## 🌐 Live Website

**Website Preview:** https://community-coffee-corner.lovable.app/

---

## 🎯 Project Objective

* Generate engaging website copy using AI.
* Apply prompt engineering techniques for consistent outputs.
* Create conversion-focused content for local businesses.
* Maintain a warm, friendly, and inviting brand tone.

---

## 🧠 Prompt Engineering Strategy

### Framework

* Role-Based Prompting
* AI acts as a professional website copywriter.

### Tone & Style

* Friendly
* Warm
* Inviting
* Conversion-focused
-----
### Constraints

* Keep the language simple and engaging.
* Match the cozy aesthetic of a neighborhood cafe.
* Produce clear and structured website content.
